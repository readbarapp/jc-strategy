用家說明：每個賽馬日應該做咩

呢份係 HKJC Quant Desk 嘅操作手冊。網站喺 GitHub Pages，收集同通知由 GitHub Actions 喺雲端跑，你唔使開住部電腦。時間一律 香港時間（Asia/Hong_Kong）。呢套工具只供研究同回測，唔係投注建議。

程式幫你做咩

  1. 賽日自動問馬會：今日沙田定跑馬地有賽？第一場官方幾點開跑？冇就收工。
  2. 開跑前抄賠率：每場開賽前 15、10、5、1 分鐘同開跑嗰下，分開抄獨贏同位置。
  3. 啡格警報：預設喺開賽前 1 分鐘，如果獨贏比起開賽前 5 分鐘平咗一半或以上，而且賠率落喺你設定範圍，就 Telegram 通知你。
  4. 完場抄派彩：官方名次、獨贏派彩、位置派彩，之後用嚟回測賺蝕。
  5. 網站即時睇：數據中心、策略回測、蒙地卡羅、Telegram 設定、日誌。

你日常最重要嘅兩件事：第一次設定好 Actions + Telegram，之後每個賽日 睇通知、完場後睇數據。排程開咗就唔使每場撳掣。

第一次設定（只需做一次）

A. 打開網站

GitHub → Settings → Pages：Source 選 Deploy from a branch，Branch 選 main，Folder 選 /docs。網址係：

https://<你的帳號>.github.io/jc-strategy/

第一次打開會見到示範歷史數據（假數據），等你未有真賽日都可以撳嚟試。

B. 畀 Actions 寫入權限

Settings → Actions → General → Workflow permissions 選 Read and write permissions。冇呢項，監控程式抄到賠率都 push 唔返 CSV。

C. Telegram 機械人

  1. Telegram 搵 @BotFather，建立 bot，複製 token。
  2. 同 bot 先傾一句，或者加 bot 入你嘅頻道。
  3. 用 @userinfobot 或者類似工具拎 chat id（頻道多數係 -100 開頭）。
  4. GitHub Settings → Secrets and variables → Actions 加：

- TELEGRAM_BOT_TOKEN

- TELEGRAM_CHAT_ID（可選；亦可以只寫喺網站 Telegram 頁）

唔好把 token 提交入 config.json。網站儲存設定時會自動刪走 token。真正監控一定讀 GitHub Secret。

D. （可選）網頁改設定、人手觸發

網站本身係靜態頁，要由瀏覽器改 repo 或者撳「觸發今日監控」，需要 Personal Access Token：

  1. GitHub → Settings → Developer settings → Personal access tokens
  2. Fine-grained：只授權呢個 repo，Contents 同 Actions 都要 Read and write
  3. 貼到網站 即時狀態 頁，撳「僅儲存授權到瀏覽器」（只留喺你部機，唔入 git）

公開 repo 睇 CSV 唔使 token；寫設定 / 觸發 Action 先要。入咗 PAT 唔等於 替你排程；賽日自動跑係 GitHub Actions。

E. 設定策略同通知

  1. 策略回測：揀投注方法、開賽前幾多分鐘（預設 1 分鐘）、獨贏賠率範圍（預設 3.5–9.0）。
  2. Telegram：同樣三項可以獨立設。可撳「抄策略設定」跟策略頁一模一樣。
  3. 開 Enable Telegram 警報，填 chat id。
  4. 撳「儲存 Telegram 設定」（要有 PAT），再「發送測試訊息」。收到測試先算接通。
  5. 數據中心 啡格門檻預設 50%。儲存參數到 GitHub，下一次 Actions 先會用新門檻。

PAT 只係網站改設定／人手觸發用。賽日自動跑靠 GitHub Actions，你唔開網站都得。

開跑前（系統自動）

  1. 偵測到今日有 ST 或 HV，並讀當日每一場官方開跑時間。
  2. 等到 當日第一場開跑前 20 分鐘 先進入高頻（預設每 10 秒問一次馬會）。沙田遲開、跑馬地提早、臨時改鐘都跟馬會當日時間。
  3. 每一場、每一隻馬，只喺呢幾個鐘點各寫一次：

- 開賽前 15 分鐘

- 開賽前 10 分鐘

- 開賽前 5 分鐘

- 開賽前 1 分鐘

- 開跑嗰下

  1. 唔抄開賽前 3 分鐘。
  2. 開賽前 1 分鐘嘅啡格，係同 開賽前 5 分鐘 嘅獨贏比。跌幅 ≥ 門檻（預設 50%），而且嗰刻獨贏喺 Telegram 範圍內，就即刻推播。每隻馬每場最多一條警報。

你呢段時間可以：

  • 睇 Telegram，唔使盯住網站
  • 想核對就開 數據中心，撳「重新載入數據」
  • 用 filter「只看符合策略」（跟策略回測頁而家嘅時間點、獨贏範圍、啡格門檻）或者「只看開賽1分鐘前出現啡格」

賽事進行中

網站唔會替你落飛。警報只係話「呢隻馬喺你定嘅規則下出現啡格」。你自己決定買獨贏、位置定兩者。

數據大約每 120 秒 先 commit 上 GitHub 一次，所以網站表格可能遲一兩分鐘，但 Telegram 係抄到嗰下即刻送。

接近開跑先 10 秒問一次馬會；隔開場次會慢到 60 秒。若被擋（429／403）會自動停一停再試。單一 Actions job 最長 6 小時，到大約 5 小時 30 分會自己再開下一段繼續抄。第一次抄到真實數據會刪晒示範假數據，之後回測只用真實場次。

最後一場完咗

監控會再等大約 25 分鐘，然後抄官方賽果（名次、獨贏派彩、位置派彩）。零晨 00:20 再補一次。

第二朝你可以：

  1. 重新載入數據
  2. 去 賽果派彩 表確認有冇 win_dividend / placedividend
  3. 去 策略回測 睇新一日加進去之後 EV 變咗未
  4. 下載獨贏 CSV、位置 CSV、賽果 CSV 自己存檔

唔係賽馬日

乜都唔使做。偵測 job 會寫「今日香港無賽馬日」就結束。網站繼續顯示舊數據。

四個分頁點用

數據中心

  • 獨贏賠率 / 位置賠率：一隻馬一行，欄位係開賽前 15／10／5／1 分鐘同開跑。啡色格 = 較上一個時間點（大約 5 分鐘前）跌 ≥ 門檻。
  • 只看啡格：任何時間點獨贏急跌。獨贏、位置、賽果派彩三張表都可以用。
  • 只看開賽1分鐘前出現啡格：淨 T-1 對 T-5 獨贏急跌。賽果派彩表同樣適用，方便你對照嗰批馬最後派咗幾多。
  • 只看符合策略：跟策略回測頁而家嘅設定揀馬（選定時間點嘅獨贏啡格 ∩ 獨贏賠率範圍 ∩ 啡格門檻）。獨贏、位置、賽果三張表都係同一批馬。投注方法只影響回測點計錢，唔影響呢個 filter。
  • 賽果派彩：官方名次同每 $10 派彩。開住啡格或者策略 filter 就只顯示對應嗰啲馬。
  • 單次快照 / 收取賽果：排程失手或者想即刻補數先用。
  • 刪除所選日期嘅紀錄：表上面揀日期（或填可選日期），刪嗰日全部賠率同賽果。要 PAT。GitHub 舊 commit 仍可還原。

策略回測 · 蒙地卡羅

揀馬永遠用 獨贏啡格 + 獨贏賠率範圍。之後先決定點結算：

  • 只買獨贏：官方獨贏派彩 − $10
  • 只買位置：官方位置派彩 − $10（唔會用獨贏去估位置）
  • 獨贏 + 位置：兩筆 $10

EV／ROI = 歷史跟呢條規則落注嘅淨盈虧 ÷ 總本金。策略頻率 = 總觸發次數 ÷ 賠率樣本入面有幾多個賽馬日（冇觸發嘅賽日都計），即大約一個賽馬日有幾多次投注機會。蒙地卡羅每年落注場次 = 頻率 × 一年賽馬日（預設 88）；模擬下注次數係隨機重抽幾多條一年路徑，估一年後賺幾多、回撤同破產機會。

Telegram 控制

投注方法、開賽前幾多分鐘、獨贏範圍可以同策略唔同。訊息會同時顯示獨贏同位置數字。要收到正式賽日警報，GitHub Secret 一定要有 bot token。

即時狀態 · 日誌

Actions 係咪運行中、今日已監控邊幾場、最近同步時間、logs/latest.log。PAT 亦係呢頁貼：只負責網站寫入同人手觸發，唔負責賽日自動排程。

人手補救（排程冇跑、中途斷網）

網站右上「觸發今日監控」= 人手跑 auto（同排程同一個命令；人手撳會即使第一場仍遠都開始等）。

數據中心：

  • 單次快照：而家即刻抄一輪所有場次（用嚟補漏，唔係完整時間序列）
  • 收取賽果：只抄派彩，唔抄即時賠率
  • 刪除所選日期嘅紀錄：清走某一日嘅古怪列，然後再用上面兩個掣補數

GitHub → Actions → HKJC Monitor → Run workflow，可以選 auto / monitor / results / once / test-telegram，日期空白就當今日香港日期。

特別情況（延誤／取消／退出）同錯數點清

監控會大約每 45 秒再問一次馬會賽程。

  • 開跑時間改咗 ≥ 2 分鐘：刪嗰場舊時間點，跟新鐘再抄。
  • 單場取消／中止／void：停抄嗰場，唔收垃圾賽果。
  • 成日賽取消或賽程消失：停抄賠率，改試收已跑完嘅賽果。
  • 延誤但馬會未改鐘：唔會當完場；等到狀態變或者改鐘，最多再等 3 小時。
  • 退出／SCR／後備馬：唔寫入、唔推 Telegram；已寫過會刪走嗰隻。
  • 仍然見到古怪列：揀嗰日 → 刪除所選日期嘅紀錄 → 收取賽果 或 單次快照。

回測只計有觸發 + 有官方派彩嘅馬。開跑前已送出嘅 Telegram 啡格收唔返。

常見問題

點解表入面有舊日子但寫住示範數據？

歷史示範係假數據，欄位同真 crawl 一樣。真賽日 Actions 會把真實賠率 追加 入同一個 CSV，唔會用產生器覆蓋真數。

點解開賽前 1 分鐘未見啡格？

要等 T-5 同 T-1 兩筆都抄到，而且獨贏跌幅真係 ≥ 門檻。3 分鐘位唔會有資料。

收到 Telegram 但網站未更新？

通知即時送；CSV 最多等兩分鐘先 push。撳「重新載入數據」。

有賽但 job 話今日無賽？

只認沙田 ST、跑馬地 HV。海外或場外投注日唔會監控。可以喺 Actions 手動跑 monitor 並填日期 YYYY-MM-DD。

回測「只買位置」係咪用開賽前位置賠率？

唔係。揀馬用獨贏啡格；結算用官方位置派彩。
